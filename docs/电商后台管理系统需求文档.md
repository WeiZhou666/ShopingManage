### 1.1 角色说明

本系统采用 RBAC（Role-Based Access Control）权限模型，按岗位分工，每个角色只能看到和操作自己职责范围内的功能。

| 角色    | 岗位       | 说明                   |
| ----- | -------- | -------------------- |
| 超级管理员 | 老板、技术负责人 | 拥有全部权限，可管理所有模块和员工账号  |
| 运营人员  | 运营专员     | 负责商品管理、价格调整、上下架、营销活动 |
| 订单专员  | 订单专员     | 负责订单处理、发货、退款审核       |
| 财务人员  | 财务/会计    | 只能看金额、流水、对账，无任何编辑权限  |
| 普通客服  | 客服       | 只能查看用户和订单，不能修改任何数据   |

### 1.2 权限矩阵

| 模块     |  超级管理员 |     运营人员     |   订单专员   | 财务人员 |  普通客服  |
| ------ | :----: | :----------: | :------: | :--: | :----: |
| 首页数据看板 |   全部   |      全部      |    全部    |  全部  |   全部   |
| 商品管理   |   全部   | **增删改查+上下架** |    只读    |   无  |    无   |
| 订单管理   |   全部   |      只读      | **全部操作** |  只读  |   只读   |
| 用户管理   |   全部   |      只读      |    只读    |   无  | **只读** |
| 物流管理   |   全部   |      只读      | **发货操作** |   无  |    无   |
| 营销活动   |   全部   |   **全部操作**   |     无    |   无  |    无   |
| 员工管理   | **全部** |       无      |     无    |   无  |    无   |
| 系统设置   | **全部** |       无      |     无    |   无  |    无   |

> **图例**：全部 = 可查看+新增+编辑+删除；只读 = 仅查看；无 = 不显示该菜单

### 1.3 员工账号规则

- 员工账号由超级管理员创建，一个员工对应一个账号
- 初始密码统一为 `123456`，首次登录强制修改
- 同一个员工不能同时被分配多个角色
- 离职后由超级管理员禁用账号，禁用后不可登录

### 2.1 登录模块

> **组件**：`Login.vue`

**功能描述**：员工输入账号密码登录系统，不同角色登录后看到不同的菜单和数据。

#### 2.1.1 登录流程

1. 输入账号 + 密码
2. 系统校验账号密码是否正确
3. 校验通过后，后端返回 Token 和员工角色信息
4. 前端保存 Token 到 localStorage
5. 根据角色信息，动态渲染左侧菜单
6. 跳转到首页

#### 2.1.2 Token 机制

| 规则        | 说明                                  |
| --------- | ----------------------------------- |
| Token 有效期 | 8 小时（会话制，工作时段有效）                    |
| Token 存储  | localStorage，key 为 `token`          |
| 请求携带      | 请求头 `Authorization: Bearer {token}` |
| 过期处理      | Token 过期后，强制跳转到登录页，显示"登录已过期，请重新登录"  |
| 主动登出      | 点击右上角"退出登录"，清除 Token，跳转登录页          |

#### 2.1.3 登录页要素

- 公司 Logo + 系统名称
- 账号输入框（placeholder：请输入账号）
- 密码输入框（placeholder：请输入密码）
- 登录按钮
- 错误提示（账号不存在 / 密码错误 / 账号已被禁用）

### 2.3 商品管理（电商核心）

> **组件**：`ProductList.vue`、`ProductEdit.vue`、`CategoryManage.vue`

**功能描述**：管理所有在售商品，是运营人员最常用的模块。

#### 2.3.1 商品列表

入口：左侧菜单"商品管理" → 商品列表

| 字段   | 说明                       |
| ---- | ------------------------ |
| 商品ID | 系统自动生成的唯一编号              |
| 商品主图 | 商品首图缩略图（点击可放大）           |
| 商品名称 | 商品标题（最多60个字符）            |
| 商品分类 | 所属分类，如：服饰、数码、美妆          |
| 价格   | 销售价（元），划线价（原价格式）         |
| 库存   | 当前可用库存数量                 |
| 状态   | **上架中**（绿色）或 **已下架**（灰色） |
| 操作   | 查看 / 编辑 / 上架/下架 / 删除     |

**列表页功能**：

- 搜索：按商品名称关键词搜索（模糊匹配）
- 筛选：按分类（下拉选择）、按状态（全部/上架/下架）
- 分页：每页显示20条，支持翻页
- 排序：按上架时间倒序（最新在前）
- 批量操作：勾选多个商品 → 批量上架 / 批量下架

#### 2.3.2 新增商品

入口：商品列表页 → "新增商品"按钮

| 字段   | 填写说明                | 必填 |
| ---- | ------------------- | -- |
| 商品名称 | 商品标题，60字以内          | 是  |
| 商品分类 | 从已有分类中选择（单选）        | 是  |
| 商品主图 | 上传商品主图，最多5张（第一张为主图） | 是  |
| 商品规格 | 如：颜色、尺码、容量（可添加多种规格） | 是  |
| 销售价  | 现价，单位元              | 是  |
| 划线价  | 原价，不填则不显示划线价        | 否  |
| 库存数量 | 商品总库存数量             | 是  |
| 商品详情 | 商品描述（富文本编辑器，支持图片）   | 是  |
| 上架状态 | 新增时默认"上架"           | -  |

**规格 SKU 说明**：

示例：一件T恤有 红色/M、红色/L、蓝色/M 三种规格变体

- 每种规格独立设置库存和价格
- 用户下单时选择规格，系统按规格扣减库存

#### 2.3.3 商品编辑

入口：商品列表 → 操作列"编辑"

可修改全部字段，包括价格、库存、上下架状态。

> **注意**：编辑后已上架商品即时生效，无需重新上架。

#### 2.3.4 商品上下架

| 操作   | 说明                |
| ---- | ----------------- |
| 上架   | 商品出现在用户端，供用户购买    |
| 下架   | 商品从用户端消失，但不影响已有订单 |
| 自动下架 | 库存为0时，自动从用户端下架    |

#### 2.3.5 商品分类管理

入口：商品管理 → 左侧子菜单"分类管理"

| 功能   | 说明            |
| ---- | ------------- |
| 查看分类 | 树形结构展示一级、二级分类 |
| 新增分类 | 输入分类名称，选择父级分类 |
| 编辑分类 | 修改分类名称        |
| 删除分类 | 该分类下有商品时不允许删除 |
| 排序   | 拖拽调整分类顺序      |

**分类示例**：

```
- 服饰
  - 女装
  - 男装
  - 童装
- 数码
  - 手机
  - 电脑
  - 配件
- 美妆
  - 护肤
  - 彩妆
- 食品
  - 生鲜
  - 零食
```

### 2.4 订单管理（公司最常用）

> **组件**：`OrderList.vue`、`OrderDetail.vue`

**功能描述**：处理所有客户订单，是订单专员每天工作的核心模块。

#### 2.4.1 订单列表

入口：左侧菜单"订单管理"

| 字段   | 说明                             |
| ---- | ------------------------------ |
| 订单编号 | 系统自动编号，格式：202605070001（年月日+序号） |
| 用户信息 | 下单用户姓名 + 脱敏手机号                 |
| 商品信息 | 商品名称 + 数量（鼠标悬停查看详情浮层）          |
| 订单金额 | 实付金额（元）                        |
| 订单状态 | 见下方状态说明                        |
| 下单时间 | 格式：YYYY-MM-DD HH:mm:ss         |
| 操作   | 查看详情 / 发货 / 退款 / 关闭订单          |

**订单状态**：

| 状态  | 颜色 | 说明              | 可执行操作    |
| --- | -- | --------------- | -------- |
| 待付款 | 橙色 | 用户提交订单，尚未支付     | 关闭订单     |
| 待发货 | 蓝色 | 用户已付款，等待发货      | **手动发货** |
| 已发货 | 紫色 | 商家已发货，等待用户收货    | 查看物流     |
| 已完成 | 绿色 | 用户确认收货，或10天自动确认 | 查看详情     |
| 已退款 | 灰色 | 款项已退回用户         | 查看详情     |
| 已关闭 | 灰色 | 付款超时或商家主动关闭     | 查看详情     |

#### 2.4.2 订单筛选

| 筛选维度    | 方式                                |
| ------- | --------------------------------- |
| 全部订单    | 默认展示所有状态                          |
| 按状态筛选   | 快捷筛选栏：待付款 / 待发货 / 已发货 / 已完成 / 已退款 |
| 按时间筛选   | 近3天 / 近7天 / 近30天 / 自定义日期范围        |
| 按订单号搜索  | 输入订单编号精确搜索                        |
| 按用户手机搜索 | 输入手机号模糊搜索用户的所有订单                  |

#### 2.4.3 订单详情

点击订单列表操作列"查看详情"进入详情页：

| 信息区块   | 字段                           |
| ------ | ---------------------------- |
| 订单基本信息 | 订单编号、下单时间、支付方式、订单状态          |
| 收货人信息  | 姓名、手机号、收货地址（含省市区）            |
| 商品信息   | 商品名称、规格、单价、数量、金额小计           |
| 价格明细   | 商品总价 + 运费 + 优惠券抵扣 = **实付金额** |
| 物流信息   | 物流公司名称、快递单号（已发货后显示）          |
| 操作日志   | 订单状态变更记录（时间+操作人+操作内容）        |

#### 2.4.4 手动发货

适用场景：用户已付款（待发货状态），商家实际发出货物。

**操作步骤**：

1. 订单专员点击"发货"按钮
2. 弹出发货表单，选择 **物流公司**（顺丰 / 中通 / 韵达 / 圆通 / 极兔 / 德邦 / 其他）
3. 填写 **快递单号**（必填，正则校验：英文字母+数字）
4. 点击确认发货
5. 订单状态变更为"已发货"
6. 系统记录操作日志（操作人、操作时间、物流信息）

> **提醒**：发货后不可撤回修改物流信息，如需修改需由超级管理员操作。

#### 2.4.5 退款处理

用户提交退款申请后，订单专员处理：

| 场景            | 处理方式           |
| ------------- | -------------- |
| 未发货退款         | 直接同意退款，款项原路退回  |
| 已发货退款（用户未收到货） | 商家确认收到退货后，同意退款 |
| 已发货退款（用户已收到货） | 商家确认货物无损后，同意退款 |

**退款状态流转**：

```
待发货 → 用户申请退款 → 待退款 → 退款完成 → 已退款
                ↓
           商家拒绝退款 → 继续发货
```

#### 2.4.6 关闭订单

适用场景：

- 用户付款超时（超过24小时未付款），系统自动关闭或商家手动关闭
- 商家缺货等特殊原因，主动联系用户后关闭

> **注意**：已付款订单不可直接关闭，必须先退款。

### 2.5 用户/会员管理

> **组件**：`UserList.vue`、`UserDetail.vue`

**功能描述**：管理所有在平台注册的买家客户。

#### 2.5.1 用户列表

入口：左侧菜单"用户管理"

| 字段   | 说明                          |
| ---- | --------------------------- |
| 用户ID | 系统唯一编号                      |
| 用户昵称 | 买家设置昵称                      |
| 手机号  | 完整手机号（脱敏展示：138\*\*\*\*0001） |
| 注册时间 | 用户注册日期，格式：YYYY-MM-DD        |
| 累计消费 | 该用户历史所有订单实付金额之和（元）          |
| 订单数  | 该用户历史有效订单数量                 |
| 用户标签 | 优质客户 / 普通客户 / 恶意用户（可多标签）    |
| 状态   | 正常（启用）/ 已禁用                 |
| 操作   | 查看详情 / 编辑标签 / 禁用            |

**筛选功能**：

- 按手机号搜索（精确匹配）
- 按标签筛选（全部/优质客户/普通客户/恶意用户）
- 按状态筛选（全部/正常/已禁用）
- 按注册时间范围筛选

#### 2.5.2 用户详情

点击用户列表"查看详情"进入：

| 信息区块 | 字段                        |
| ---- | ------------------------- |
| 基本信息 | 用户ID、昵称、手机号、注册时间、最后登录时间   |
| 消费统计 | 累计消费金额、订单总数、平均客单价（消费/订单数） |
| 收货地址 | 该用户保存的收货地址列表（可设置默认地址）     |
| 订单记录 | 最近10条订单（订单号/商品/金额/状态/时间）  |
| 优惠记录 | 已领取优惠券、已使用优惠券统计           |
| 操作日志 | 操作记录（禁用/打标签等）             |

#### 2.5.3 禁用用户

**禁用条件**：发现恶意下单、刷单、诈骗等行为的用户。

**禁用后效果**：

- 用户账号无法登录
- 历史订单数据保留
- 用户端显示"账号异常"

**解禁**：超级管理员可重新启用。

#### 2.5.4 用户标签

| 标签   | 说明                 | 颜色标识  |
| ---- | ------------------ | ----- |
| 优质客户 | 累计消费满1000元或订单数≥10单 | 金色/黄色 |
| 普通客户 | 无特殊标签的默认用户         | 灰色    |
| 恶意用户 | 被禁用或被标记的用户         | 红色    |

标签由运营人员手动打标，也可根据消费金额自动打标（系统规则）。

### 2.6 物流管理

> **组件**：`LogisticsCompany.vue`、`ShipmentRecord.vue`

**功能描述**：管理物流公司和查看发货记录。

#### 2.6.1 物流公司配置

入口：左侧菜单"物流管理" → 物流公司

| 字段     | 说明                    |
| ------ | --------------------- |
| 物流公司名称 | 如：顺丰速运、中通快递           |
| 物流代码   | 快递100/菜鸟接口代码，如：SF、ZTO |
| 官网     | 物流公司官网链接              |
| 状态     | 启用 / 停用               |

**功能**：新增 / 编辑 / 删除 / 启用停用

#### 2.6.2 发货记录

入口：左侧菜单"物流管理" → 发货记录

| 字段   | 说明              |

## 三、RBAC 权限控制实现说明

### 3.1 前端权限控制

1. **动态菜单**：员工登录后，根据角色从后端获取可访问的菜单列表，前端只渲染有权访问的菜单项
2. **按钮级控制**：对于同一页面内的不同操作按钮（如"编辑"和"删除"），前端根据角色判断是否显示
3. **路由守卫**：用户访问某个URL时，前端检查该路由是否在角色允许范围内，不在范围内则跳转404或无权限页

### 3.2 后端权限控制

1. **接口级拦截**：每个 API 请求后端验证当前 Token 对应的角色是否有权访问该接口
2. **数据隔离**：财务人员查询订单时，仅返回订单金额等字段，不返回用户手机号等敏感信息
3. **操作日志**：所有敏感操作（删除商品、关闭订单、退款审批、禁用用户等）记录操作人、操作时间、操作内容

### 3.3 权限点清单

以下操作需要记录操作日志：

| 模块 | 操作                       |
| -- | ------------------------ |
| 商品 | 新增商品、编辑商品、删除商品、上架/下架     |
| 订单 | 关闭订单、发货、退款审批、退款拒绝        |
| 用户 | 禁用用户、解禁用户、修改用户标签         |
| 营销 | 创建/编辑/删除优惠券、创建/编辑/删除秒杀活动 |
| 员工 | 新增员工、编辑员工、禁用员工、重置密码      |
